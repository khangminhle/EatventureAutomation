# 🎮 Eatventure Automation

If you're interested in this game, join me.

This small project uses Python.

---

## 🚀 Simple functions
* 🖼️ Upgrade food stalls (a red circle with a white up arrow)
* 📦Open crates
* 📊 Upgrade shop (an up arrow at the right bottom corner)
* ⚡ Finish and go to the next city
---

## 🛠️ Requirements
Before installation, please ensure your system meets below requirements:
* **Python 3.10 or newer** (Python 3.11 is better).
* **Git**.
* *(For Android mobile only)*: know how to activate **Developer Options** and **USB Debugging**.
* Especially, you must install this game.

---

## 📦 Full detailed installation

Open your terminal or Command Prompt on Windows) and run below lines:

### 1. Clone project
```
git clone https://github.com/khangminhle/EatventureAutomation.git
cd ten-du-an
```
### 2. Create a new virtual environment.
For Windows
```
python -m venv venv
venv\Scripts\activate
```
For Linux (I use Ubuntu)
```
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Python libraries
```
pip install --upgrade pip
pip install -r requirements.txt
```
### 4. Run the program
```
python3 auto.py
```
🔥 Enjoy 🔥
